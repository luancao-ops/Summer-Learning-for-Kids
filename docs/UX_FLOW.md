## 1. Student Selection Flow (Chọn học sinh)

```
┌─────────────────────────────────────────────────────┐
│                   SUMMER QUEST                       │
│              🌟 Chọn nhân vật của bạn 🌟             │
│                                                     │
│   ┌──────────────┐        ┌──────────────┐          │
│   │   👑 [Tên]   │        │  🤖 [Tên]   │          │
│   │  Công chúa   │        │  Kỹ sư Robot │          │
│   │              │        │              │          │
│   │  Level 3     │        │  Level 2     │          │
│   │  🔥 Streak 5 │        │  🔥 Streak 2 │          │
│   │              │        │              │          │
│   └──────────────┘        └──────────────┘          │
│                                                     │
│              [Phụ huynh vào đây →]                  │
└─────────────────────────────────────────────────────┘
```

**Luồng:**
1. App load → trang `/` (Student Selection)
2. Hiển thị 2 profile cards, mỗi card có: avatar, tên, level, streak hiện tại
3. Bé bấm vào card của mình → animation hover scale-up
4. Navigate đến `/[studentId]/dashboard`
5. Theme áp dụng ngay khi vào dashboard (màu sắc, background)

**Edge cases:**
- Nếu là ngày đầu tiên (streak = 0): hiển thị "🌱 Ngày đầu tiên!" thay vì streak
- Loading: skeleton placeholder trong 300ms

## UX Rules tổng hợp

| Rule | Áp dụng cho |
|---|---|
| Không bao giờ hiển thị "0 điểm" hoặc "Thất bại" | Quiz Engine |
| Luôn cho phép quay lại bước trước | Lesson Viewer |
| Feedback âm tính phải kèm gợi ý hướng đi | Quiz Engine |
| Animation mọi transition > 100ms | Toàn app |
| Font size tối thiểu 16px cho nội dung | Toàn app |
| Button tối thiểu 44×44px | Toàn app |
| Không có đồng hồ đếm ngược trong quiz | Quiz Engine |
| Badge modal không thể bị bỏ qua (must close) | Reward System |
| Màu theme áp dụng ngay khi chọn profile | Theme System |
